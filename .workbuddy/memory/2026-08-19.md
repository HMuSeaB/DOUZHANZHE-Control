## README 截图修正为深色主题
- 用户反馈首版截图是浅色。排查后发现不是后端 bug：后端 `/api/ui-state` 正确返回 `"theme":"auto"`，app 在 `App.jsx:53` 通过 `window.matchMedia('(prefers-color-scheme: dark)')` 跟随系统。
- 真相：用户 Windows 是深色 → app 显示深色；无头 Edge 默认 `prefers-color-scheme:light` → app 的 `auto` 模式在无头环境解析成浅色 → 截图浅。
- 修复：截图脚本加入 Playwright `colorScheme: 'dark'`，使无头浏览器模拟系统深色，7 个 tab 全部重截为深色。同时修正 `screenshot-spa-tabs` skill 默认 `COLOR_SCHEME=dark` 并补充文档。
